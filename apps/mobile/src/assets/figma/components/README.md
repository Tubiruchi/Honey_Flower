# Recursos originales de Componentes

Exportados de [Joyner · Componentes](https://www.figma.com/design/VL7t5V9yd9nt1mkr0DpKJj/Joyner?node-id=65-676)
el 18 de octubre de 2026. `index.ts` conserva referencias locales, sin URLs temporales en ejecución.

- `icons-*`: los 26 maestros de iconos, nodo `65:793`.
- `switch-*`: los seis estados originales de `66:1036` a 48 × 48.
- `plant-*`: ojos abiertos/cerrados de `65:794` a 320 × 260.
- `feedback-*`, `weekly-*`, `calendar-*`: iconos de las variantes `67:877`, `67:977` y `118:1943`.
- `character-*`: PNG originales Brote/Cactus de `118:1864`; los rostros conservan los recortes de las instancias.
- `greenhouse-*`, `backdrop-*`: ilustraciones de entorno de `131:2175` y `142:2206`.

Los SVG se guardan sin editar su contenido o geometría. Los iconos monocromos pueden heredar
el color semántico del control mediante una máscara CSS con el recurso original.
El onboarding conserva sus ilustraciones específicas en la carpeta hermana `onboarding`.
